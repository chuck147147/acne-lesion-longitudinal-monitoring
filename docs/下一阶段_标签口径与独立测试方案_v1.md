# 痤疮逐框分类：标签口径与独立评估方案 v1

## 当前状态

- 训练照片、受试者划分清单和模型检查点保存在本地，不随公开仓库发布。
- 模型或数据版本变化后，应重新记录受试者级划分和逐类指标。
- 开发集结果不能代替来自未见受试者的独立测试；没有独立测试时，不应宣称模型已验证跨受试者泛化。

## 标签口径

保留现有模型的五个标签，以免打断 V2 数据与权重：

| 现有标签 | 逐框操作定义 |
| --- | --- |
| 0* | 框内只有痘印或瘢痕，没有可见活动性皮损 |
| I | 开放或闭合粉刺 |
| II | 炎性丘疹，未见脓疱、结节或囊肿 |
| III | 脓疱，未见结节或囊肿 |
| IV | 结节或囊肿 |

这里的 `box_severity_grade` 是项目的**逐框类别**：一个框只圈一个目标；同一框无法拆开的混合皮损按框内最高类别标注；无法可靠判断时标“不确定”，不要猜级别。0* 是项目的后遗变化类别，不是指南中的痤疮 I～IV 级。

临床分级应另设**照片/受试者/就诊级**字段。中国基层诊疗指南按粉刺、炎性丘疹、脓疱、结节/囊肿的皮损性质定义 I～IV 级，并强调不按皮损数量分级；因此逐框类别不能直接称为受试者整体临床严重程度。[基层诊疗指南（2023年）](https://cqrc120lib.yuntsg.com/ueditor/jsp/upload/file/20230918/1695046778925091269.pdf)

建议后续的照片级字段为 `face_grade`（0*、I、II、III、IV）和 `grade_reviewer`。仅凭一张局部照片不能判定未拍摄区域；结果应写作“照片可见区域分级”。疑似结节/囊肿或照片不足以定级时，允许“不确定/需复核”。

## 划分规则

1. **划分单位是受试者，不是框。** 同一受试者的所有照片、角度和随访时间点只进入 train、val、test 中的一个集合。
2. **划分前先固定名单。** 先登记匿名 `participant_id`、照片和会话，再锁定 test 名单；test 照片不用于训练、调参、阈值选择或示例筛选。
3. **开发阶段数据暂不作为独立受试者验证集。** 若照片尚未关联匿名受试者 ID，或未确认按受试者隔离，不得将其称为独立受试者验证结果。
4. 新测试照片必须来自训练数据中未出现的受试者；先核对身份组，再运行 `scripts/audit_subject_split_manifest.py`。
5. 保留原始照片，另存标注与推理结果；不要通过重命名同一张照片把它变成新测试样本。

## 独立测试批次采集

- 使用匿名编号（如 `SUBJECT_001`），不要在清单里写姓名、联系方式等身份信息。
- 同一受试者尽量拍正面、左侧、右侧；记录会话编号、日期、视角、设备和清晰度。连续拍摄的同一轮照片作为同一会话。
- 尽量统一距离、光线和拍摄角度；保留常见手机拍摄差异，但标记模糊、强反光、遮挡等质量问题。
- 确认受试者已同意用于项目研究；无法确认授权的照片不纳入数据集。
- 独立测试中的类别比例按真实采集分布保留，不为“平衡”测试集而复制少数类图片。

## 复核与报告

- 独立测试框由第二位标注者盲标一部分，并在看模型输出前完成；分歧由双方复核，疑难病例交由皮肤科专业人员。
- 分类器报告 Top-1、macro-F1、每类 precision/recall、混淆矩阵和按受试者汇总的结果；同时注明受试者数、照片数、框数及不确定框数。
- 检测器和逐框分类器分开评价：检测报告 mAP/recall，分类器只在参考框裁剪图上报告分类结果。另报告端到端结果时，应明确错误来自漏检、误检还是错分。
- 若目标是长期监测，留出至少一组未参与训练的重复拍摄/随访会话，按同一受试者配对评价病灶持续、新发、消退和趋势。

## 下一步执行顺序

1. 对本地照片清单填写可确认的日期、会话或相对顺序；未知时间保持空白。使用匿名受试者编号，不在清单中保存姓名或联系方式。
2. 按本方案收集全新受试者的独立测试照片，运行 `scripts/prepare_photo_annotation_pilot.py` 生成候选框并逐框盲标。
3. 运行 `scripts/register_independent_test_batch.py` 登记照片，再补齐匿名受试者 ID；已知拍摄会话时填写会话 ID，`split` 保持 `test`。
4. 运行 `scripts/audit_subject_split_manifest.py` 检查路径、信息缺失和受试者跨集合；通过后运行 `scripts/evaluate_box_severity_on_independent_test.py`。发现错误后先做错误分析，再决定是否补标或训练 V3。
