# 既有痤疮项目与图像资源复用评估 V0.1

> 评估日期：2026-10-25。用途：判断公开成果、数据和项目内示例照片能否用于本项目的 YOLO 基线、类别设计和长期追踪研究。此文档不是数据授权意见。

## 结论

可以直接借鉴既有检测流程，也有一个可快速试跑的四类公开数据候选；但公开论文中的照片、项目规范里的分级示例图，并不等于可训练的数据集。现有公开数据大多没有跨随访病灶 `track_id`，因此可支持单张照片 YOLO 基线，不能单独验证本项目的病灶级长期追踪。

## 已有图像与成果

### 1. 项目规范文档中的两张照片

当前 [研究问题与标注规范 V0.1](./研究问题与标注规范_v0.1.md) 第 7 节引用了：

- 湖北省第三人民医院科普页的一组痤疮分级照片：可帮助人工理解严重度外观；网页没有给出可用于机器学习的数据集、逐颗框标注或随访身份信息。不能因为图片能显示，就默认可以拿来训练或公开再发布。
- CDC PHIL 的 Grade IV 结节囊肿型痤疮照片：页面标注了临床级别，适合作为重度外观参考；单张示例没有逐病灶框标注，也没有本项目所需的跨期身份信息。CDC 页面提供公共领域使用说明和署名要求。

这两处图像是**教学/分级示例**，不是可供 YOLO 训练的病例数据集。适合保留在标注指南里，不能用来计算训练集指标。

### 2. ACNE04：适合单类检测基线

- 规模：论文报告 1,457 张照片、18,983 个病灶框；每颗病灶只有一个通用 acne 类别，没有粉刺、丘疹、脓疱、结节等细分类。
- 价值：最适合先复现“照片里能不能找到痤疮病灶、能不能计数”的单类 YOLO 基线。既有研究也用 YOLOv4 在 ACNE04 上做过检测。
- 限制：一项后续复核指出原数据有低质量照片，并对框做过收紧；因此下载后应先检查模糊、远景、框过大和错误样本。该项目仓库明确写明“学术用途免费”，其他用途联系作者；按该说明引用论文并保留用途记录。
- 入口：[原始项目和数据说明](https://github.com/xpwu95/LDL)；[ACNE04 检测研究与清洗说明](https://pmc.ncbi.nlm.nih.gov/articles/PMC9028662/)。

### 3. Roboflow Acne Detection V1：最接近四类 YOLO 试跑

- 页面列出 1,419 张图、四类框：`comedone`、`nodule`、`papule`、`pustule`，并声明 CC BY 4.0。类别可映射到一个简化版 YOLO 初始模型。
- 它没有说明数据来源、拍摄设备、医生标注流程或描述；`comedone` 也未区分开放/闭合粉刺。网页许可证不能自动证明上传者拥有每张人脸照片的再授权权利。
- 判断：可以作为**快速工程试跑候选**，但训练前要抽查原图、标注和重复图片；正式报告前记录下载版本、来源、许可证和署名。不能把它的测试集结果当成可靠临床泛化结论。
- 入口：[数据集页面](https://universe.roboflow.com/acne-project-2auvb/acne-detection-v1)。

### 4. 手机 AcneDet 研究：最值得借鉴拍摄和标注设计

- 研究使用 1,572 张 iOS/Android 手机照片，由四名皮肤科医生完成标注并由资深医生复核；每张包含病灶框和 IGA 0–4 分级。
- 四类把开放/闭合粉刺合并、丘疹/脓疱合并、结节/囊肿合并，并把瘢痕作为一类；和本项目的细分标签不完全一致。论文报告检测 mAP 0.54，黑白头类别 AP 0.40，丘疹/脓疱 AP 0.64，结节/囊肿 AP 0.68，瘢痕 AP 0.44。
- 方法可改造：三视角采集、手机端距离/光线门控、人工质检、初级医生标注加资深复核，以及“先检测计数、再按规则估级”的可解释输出。
- 数据限制：论文说明了研究数据的来源和用户同意流程，但未在文中给出可直接下载的原始训练图像包；不能把论文图当成 1,572 张训练集。

### 5. AcneSCU 与 ACNE-DET：细分类参考，先确认授权

- AcneSCU 来自 VISIA 标准化成像，公开介绍提供 276 张高分辨率图像，细分类信息比 ACNE04 丰富；与普通手机照片有设备域差异。项目仓库说明数据需联系作者获取，且仅限非商业使用；代码仓库的 Apache-2.0 许可不等于数据许可。
- ACNE-DET 项目给出 LabelMe 格式数据的下载入口，但仓库没有清楚展示数据集许可。可研究它的标签结构和检测设计；下载后用于训练或公开成果前应向数据作者确认许可范围。
- 入口：[AcneSCU 代码及数据申请说明](https://github.com/pingguokiller/acnedetection)；[ACNE-DET 项目](https://github.com/INno-Vation/Decoupled-Sequential-Detection-Head)。

## 本项目的复用决定

| 资源 | 可直接用于什么 | 不能直接支撑什么 | 建议 |
|---|---|---|---|
| 项目规范里的医院/CDC 示例照 | 标注员学习分级和外观 | YOLO 训练、独立测试、跨期追踪 | 留作指南图；CDC 图按页面要求署名，医院图先核授权 |
| ACNE04 | 单类病灶检测与计数基线 | 四/五类识别、手机场景鲁棒性、病灶 ID 追踪 | 可先训单类 YOLO；做质量清点，按受试者划分数据 |
| Roboflow 四类集 | 快速测试 YOLO 多类训练链路 | 可靠的临床结果或细分开放/闭合粉刺 | 先小规模抽检；记录来源和版本，检查重复与错误框 |
| AcneDet 论文与示例图 | 手机采集门控、标注流程、输出设计 | 直接训练其原始模型或复用整套数据 | 复制流程思想；数据需联系作者获取并另核权利 |
| AcneSCU / ACNE-DET | 类别体系、细粒度检测方法 | 未授权时直接用于训练或再发布 | 先按仓库说明申请/确认许可，再做类别映射 |

## 建议的第一轮实验

1. **先跑单类 ACNE04 YOLO 基线**：确定图片读取、标签转换、训练、验证、可视化和计数流程是否工作；用 mAP、Precision、Recall、计数 MAE 汇报，不宣传为细分类能力。
2. **再试 Roboflow 四类候选**：先随机检查约 100 张图和框；把 `comedone` 暂时映射成“粉刺（未区分开闭）”，把其余三类分别映射到结节、丘疹、脓疱；与本项目最终标签保持显式映射表，不把合并标签伪装成细分类。
3. **使用自有照片做目标域抽检/小样本微调**：拍摄条件、受试者授权和数据伦理先落实；按受试者分组切分，严禁同一人的相邻随访图泄漏到训练和测试两侧。
4. **长期追踪单独建数据**：对同一人重复照片逐病灶标 `track_id`、持续/消退/新发/不确定。普通公开单次照片数据不包含这类真值。文献中的 AcnePA2 有 74 人、148 张纵向手机图，可作为申请数据的线索，但公开论文提及纵向图像不代表已提供逐病灶 ID 标签；需要联系作者确认能否申请以及标注层级。
