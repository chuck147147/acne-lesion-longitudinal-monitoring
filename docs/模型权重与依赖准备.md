# 模型权重与依赖准备

本仓库发布代码和说明，不包含面部照片、训练数据或模型权重。克隆仓库后，桌面程序不会自动下载模型；请只使用你有权访问和使用的权重。

## 三图监测所需权重

默认位置如下：

| 用途 | 默认文件 | 兼容要求 |
| --- | --- | --- |
| 痤疮候选框检测 | `runs/detect/acne04_yolo11n_fold0/weights/best.pt` | Ultralytics YOLO 检测模型，单类痤疮候选框 |
| 逐框类别分类 | `runs/classify/acne_box_severity_yolo11n_v2_finetune/weights/best.pt` | Ultralytics 分类模型，类别映射需覆盖 `0*`、`I`、`II`、`III`、`IV` |
| 面部锚点 | `weights/face_landmarker.task` | MediaPipe Face Landmarker 任务模型 |

桌面入口使用默认路径。命令行可用 `--detector`、`--classifier` 和 `--landmarker` 指定其他位置。只准备检测器还不能运行完整三图监测；分类器和面部关键点模型也必需。

## 安装依赖

在仓库根目录运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-monitor.txt
```

训练依赖在 `requirements-training.txt` 中，当前采用 CUDA PyTorch 配置。CPU、非 NVIDIA 显卡或不同 CUDA 环境需按 PyTorch 官方安装指引选择对应版本，再安装其余训练依赖。配准核心的直接依赖列在 `requirements-tracking.txt`。
