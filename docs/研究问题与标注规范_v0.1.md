# 病灶级痤疮长期监测：研究问题与标注规范 V0.1

> 状态：项目启动草案，适用于小规模试标注和方法验证。不是临床诊断或治疗指南。
> 分级工作口径：先按《中国痤疮治疗指南（2019 修订版）》常用的 3 度 4 级整理；正式研究前，需对照 2025 年《中国专家共识》全文确认严重度及疗效评价方案。

## 1. 研究问题

### RQ1：逐颗病灶追踪是否比总数变化更完整地反映病灶变化？

- **比较对象**：仅比较每次总数；与比较每颗病灶的持续、消退、新发和类型变化。
- **参考判定**：皮肤科医生对盲化的同一受试者照片对进行复核，标记病灶变化；无法确认的配对标为“不确定”。
- **主要输出**：病灶级新发/消退识别的 precision、recall；总数变化的 MAE；与医生变化判断的一致性。
- **措辞边界**：结果只能说明对照片中病灶变化的刻画是否更完整，不能据此声称更能代表患者整体病情或治疗效果。

### RQ2：普通手机重复拍摄造成的测量误差有多大？

- 在短时间内重复拍摄同一受试者，尽量保持皮肤状态不变，同时记录现实中常见的距离、角度、光线变化。
- 测量检测数量和面积指标的重复性，并估算“最小可检测变化”（MDC）。MDC 表示超出拍摄/测量噪声的界限，不等同于临床重要变化。
- 另设真实随访照片对，由医生判断变化方向，用来检验阈值是否漏掉实际变化。

### RQ3：配准、质量门控和时间确认能否减少假变化？

用同一批随访照片逐项比较：

1. 原始照片直接比较；
2. 加入面部锚定配准；
3. 再加入拍摄质量门控；
4. 再加入连续时间点确认。

分别报告假好转率、假恶化率、真实变化检出率和确认延迟。时间确认可能减少短期误报，也可能延迟变化提示，因此四项指标要一起看。

## 2. 临床分级层

本项目先将分级作为**临床参考标签**记录。模型的原始输出仍是病灶类型、数量和分布；不要把“分类器预测等级”当成病灶检测结果。

| 项目等级 | 活动性皮损表现 | 归级规则 |
|---|---|---|
| 0* | 无可见活动性粉刺、丘疹、脓疱、结节/囊肿 | 项目随访状态，非指南 I～IV 级 |
| I（轻度） | 仅有开放或闭合粉刺 | 没有炎性丘疹、脓疱或结节/囊肿 |
| II（中度） | 有炎性丘疹，可伴粉刺 | 未见脓疱或结节/囊肿 |
| III（中度） | 有脓疱，可伴粉刺、丘疹 | 未见结节/囊肿 |
| IV（重度） | 有结节或囊肿，可伴其他活动性皮损 | 按最高严重度活动性皮损归级；疑似深部皮损需医生复核 |

**分级注意事项**

- 这是便于项目启动的操作化版本；不要混入另一套 Pillsbury 国际改良分级的数量阈值。
- 本表按可见皮损类型分层，病灶数量、面部分区和累及范围另行记录。
- 仅有痘印或瘢痕、没有活动性皮损时，记为 0 级并记录后遗变化。
- 若只拍面部，结果称“面部影像分级”，不外推为胸、背、颈部在内的整体严重度。

## 3. 病灶分类与标注规则

### 3.1 主标签

| 标签 | 判定要点 | 标注备注 |
|---|---|---|
| 开放粉刺 | 毛囊口可见深色角栓 | 与普通色素点或毛发无法区分时标“不确定” |
| 闭合粉刺 | 小而肤色/白色的隆起，未见明显开口 | 手机照片分辨率不足时允许标“不确定” |
| 炎性丘疹 | 红色、隆起、未见明确脓头 | 记录为活动性炎性病灶 |
| 脓疱 | 隆起的炎性病灶，中央可见白/黄色脓头 | 记录为活动性炎性病灶 |
| 结节/囊肿 | 较深、较大或明显隆起的炎性皮损 | 仅凭照片难确认深度；临床分级由医生复核 |
| 炎症后红斑/色素沉着 | 扁平的红色、棕色或灰褐色痕迹 | 单独记录，不计活动性病灶数 |
| 瘢痕 | 萎缩性凹陷或增生性隆起等结构改变 | 单独记录，不计活动性病灶数 |

“痘印”应至少拆成炎症后红斑和炎症后色素沉着；瘢痕再区分萎缩性与增生性。初版可以先记录“有/无”和分区，后续有皮肤科标注者再细分。

### 3.2 框、分区与跨时间点 ID

- 每个可分辨的病灶单独画框；相邻但边界清楚的病灶分别标注。融合成片、无法逐颗拆分时标为“融合区域”，不要用一个大框伪装成单颗病灶。
- 面部分区建议固定为：额头、鼻部、左脸颊、右脸颊、下巴/下颌。左右按受试者自身左右，不按图像左右；跨区病灶按中心点所在区分配。
- 每张图为每个框保存 `image_id`、`lesion_id`、类别、框坐标、分区、可见性/不确定标记和标注者。
- 跨时间点另建 `track_id`，状态限于：持续、消退、新发、类型变化、不确定。只有在配准后位置和形态都支持时才沿用同一 ID；“附近又长了一颗”不能自动判为原病灶持续。
- 质量不足时保留图像级拒收原因，不要把看不清的区域标成阴性。

### 3.3 面积指标

检测框面积不等于病灶真实面积。若要报告归一化病灶面积，应增加病灶轮廓分割标注；若暂时只有 YOLO 框，应把指标写成“检测框面积占比”，不能称为病灶面积。

## 4. 拍摄与质量门控

### 建议的采集条件

- 同一受试者尽量固定手机、镜头、距离、照明、背景和拍摄角度；关闭美颜、滤镜、人像虚化和自动修图。
- 每次至少拍正面、左侧、右侧三个视角；头发、口罩、手或强反光不得遮住主要区域。
- 记录设备型号、视角、拍摄时间、闪光灯状态，以及近期是否化妆/使用会改变皮肤外观的产品；不要求在照片中显示身份信息。
- 同一随访系列尽可能保持相同构图。若拍摄条件变化，标记变化原因，不把配准结果自动解释为病情变化。

### 图像准入字段

每张图片先判为“可分析”或“拒收/需重拍”，并可多选原因：失焦、运动模糊、过曝/欠曝、颜色偏移、姿态偏转、脸部遮挡、裁切不全、滤镜/美颜、非目标部位或其他。

## 5. 标注与复核流程

1. 先用 30～50 张图试标，修订类别边界和拒收规则。
2. 两名标注者独立标一部分图像；对类别冲突、分级冲突、病灶匹配冲突由皮肤科医生裁定。
3. 每次修改标注规范都记录版本号、日期和变更原因；同一正式数据集锁定一个规范版本。
4. 数据按受试者划分训练/验证/测试集。同一人的不同日期、不同角度照片必须留在同一数据分区，避免身份和背景泄漏。
5. 保存原始影像与脱敏后的研究副本；只收集完成研究所需的资料，并限制访问权限。涉及受试者照片的研究，先与导师/伦理管理部门确认适用流程和授权文本。

## 6. 评估指标清单

| 模块 | 建议指标 | 说明 |
|---|---|---|
| 病灶检测 | 每类 Precision、Recall、F1、AP、mAP@0.5、mAP@0.5:0.95 | 按病灶类别分别报告，避免总 mAP 掩盖粉刺等困难类别 |
| 数量估计 | 每类计数 MAE、偏差、绝对误差分布 | 同时报告不同严重度和拍摄质量下的误差 |
| 人工标注一致性 | 类别 Cohen’s κ；数量 ICC 或计数差异 | 医生裁定集作为参考；多名标注者时说明统计方法 |
| 面部配准 | 面部锚点归一化误差、失败率 | 误差除以固定人脸尺度，如双眼间距；报告配准失败样例 |
| 病灶追踪 | 匹配 Precision/Recall、ID switch、未匹配/不确定比例 | 以医生复核的跨期病灶配对为参考 |
| 重复拍摄可靠性 | 同次重复拍摄的计数差、面积差、ICC、MDC | 同次照片应作为“预期无真实变化”的噪声样本 |
| 趋势误报 | 假好转率、假恶化率、无变化区间误报数 | 以受试者-随访区间为单位；同时报告置信区间 |
| 时间确认 | 真实变化检出率、误报率、确认延迟 | 与不启用时间确认的基线比较 |
